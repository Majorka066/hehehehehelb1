# Ход выполнения работы

## Результат ЛР 1

В рамках лабораторной работы был создан начальный проект веб-приложения на тему:

**«Планировщик мероприятий — события и регистрация на них»**.

Проект организован с использованием React, TypeScript и Vite.

## Шаг 3

Был создан frontend проекта с использованием Vite и шаблона React + TypeScript.

Установлены необходимые зависимости проекта.

Проверка выполнена запуском:

```bash
npm run dev
```

Приложение успешно запускается в режиме разработки.

## Шаг 4

Был создан начальный экран приложения.

Добавлены:

- название «Планировщик мероприятий»;
- описание приложения;
- раздел «Предстоящие мероприятия»;
- базовое собственное оформление;
- русская локализация страницы через `lang="ru"`;

- стандартные логотипы;
- неиспользуемые импорты.

## Шаг 5

Проверена структура проекта и корректность работы frontend.

Исходный код разделён между файлами:

- `src/App.tsx`;

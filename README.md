# Планировщик мероприятий

## Тема

Планировщик мероприятий — события и регистрация на них.

## Автор

Мотузок И.С.

## Группа

24ПИ-2

## Описание

Веб-приложение предназначено для планирования мероприятий, просмотра списка событий и регистрации пользователей на мероприятия.

Основной сценарий работы:

1. Пользователь открывает приложение.
2. Просматривает список доступных мероприятий.
3. Выбирает интересующее мероприятие.
4. В дальнейшем сможет зарегистрироваться на выбранное мероприятие.

## Версия Node.js

Для работы проекта требуется Node.js.

Проверить установленную версию можно командой:

```bash
node -v
```

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

После запуска откройте адрес, который будет указан в терминале.

Обычно это:

```text
http://localhost:5173
```

## Проверка сборки

Остановите dev-сервер через:

```text
Ctrl+C
```

Затем в папке `frontend` выполните:

```bash
npm run build
npm run preview
```

## Что работает сейчас

В рамках ЛР 3 приложение дополнено локальным управлением мероприятиями. Реализованы:

- создание нового мероприятия через форму;
- редактирование существующего мероприятия той же формой;
- удаление с подтверждением;
- проверка обязательных полей, даты окончания и рейтинга;
- фильтрация списка по статусу и сброс фильтра;
- отдельные состояния для пустого списка, отсутствующего фильтра и неизвестного адреса;
- общие layout, навигация и адаптивное оформление из ЛР 2.

## Адреса страниц

| Адрес | Назначение |
| --- | --- |
| `/` | Перенаправление к списку |
| `/events` | Список мероприятий |
| `/events/event-1` | Пример карточки мероприятия |
| `/events/new` | Создание мероприятия |
| `/events/event-1/edit` | Редактирование мероприятия |
| `/events/missing` | Отсутствующее мероприятие |
| `/unknown` | Неизвестная страница |

## Текущие ограничения

Мероприятия хранятся только в памяти открытой вкладки. После обновления страницы восстанавливается демонстрационный набор из ЛР 2. HTTP, Supabase и постоянное хранение данных пока не подключены.

# Планировщик мероприятий

## Тема

Планировщик мероприятий — события и регистрация на них.

## Автор

Мотузок И.С.

## Группа

24ПИ-2

## Описание

Веб-приложение предназначено для планирования мероприятий, просмотра списка событий и регистрации пользователей на мероприятия.

Основной сценарий работы:

1. Пользователь открывает приложение.
2. Просматривает список доступных мероприятий.
3. Выбирает интересующее мероприятие.
4. В дальнейшем сможет зарегистрироваться на выбранное мероприятие.

## Версия Node.js

Для работы проекта требуется Node.js.

Проверить установленную версию можно командой:

```bash
node -v
```

## Запуск

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

После запуска откройте адрес, который будет указан в терминале.

Обычно это:

```text
http://localhost:5173
```

## Проверка сборки

Остановите dev-сервер через:

```text
Ctrl+C
```

Затем в папке `frontend` выполните:

```bash
npm run build
npm run preview
```

## Что работает сейчас

В рамках ЛР 2 начальный экран развит до SPA с маршрутизацией. Реализованы:

- список из шести демонстрационных мероприятий;
- повторно используемая карточка с типизированными props;
- подробная страница каждого мероприятия, выбираемого по `id` из URL;
- страница-заглушка для будущей формы создания;
- общие layout и навигация с активным пунктом;
- отдельные состояния для неизвестного адреса и отсутствующей записи;
- адаптивное оформление для ноутбука и экрана шириной 360 px.

## Адреса страниц

| Адрес | Назначение |
| --- | --- |
| `/` | Перенаправление к списку |
| `/events` | Список мероприятий |
| `/events/event-1` | Пример карточки мероприятия |
| `/events/new` | Заглушка создания |
| `/events/missing` | Отсутствующее мероприятие |
| `/unknown` | Неизвестная страница |

## Текущие ограничения

Мероприятия пока хранятся в типизированном демонстрационном массиве. HTTP, Supabase, создание, редактирование и удаление данных на этом этапе не подключаются. Рабочая форма появится в ЛР 3.
